# Peripheral

Bare-metal STM32F103C8T6 peripheral examples.

## Examples

| Example | Description |
|---|---|
| [00-gpio-input](00-gpio-input/) | GPIO input polling with PA0 button and PC13 LED |
| [01-exti-button](01-exti-button/) | GPIO external interrupt using EXTI and NVIC |
| 02-uart-polling | USART communication using polling |
| 03-uart-interrupt | USART communication using interrupts |
| 04-timer-interrupt | STM32 timer interrupt |
| 05-pwm | Timer PWM output |
